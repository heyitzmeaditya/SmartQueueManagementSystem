# Smart Queue Management System

This is a full-stack web project made to manage customer queues in a smart and digital way. Instead of standing in long physical lines, people can be added to a digital queue and their turn is managed automatically. This project is useful for places like hospitals, banks, service centers, and offices.

## Why I Made This Project
In many places, queues are managed manually which causes:
- Long waiting time  
- Crowd problems  
- Confusion about turn  
- No live update  
So, I built this system to manage everything digitally and in real time.

## What This Project Can Do
- Create queues
- Add customers to the queue
- Give each customer a token number
- Show live queue status
- Remove customer after service is done
- Secure login system
- Real-time updates using sockets
- Works on both mobile and desktop

## How This Project Works (Simple Flow)

1. Admin logs into the system  
2. Admin creates a queue  
3. Customers are added to the queue  
4. Every customer gets a token number  
5. Live queue updates happen in real time  
6. After service, the customer is removed from the queue  

## Environment Setup

Create a `.env` file in the backend folder and add:
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key

## How to Run This Project on Your Laptop

### Step 1: Clone the Project
git clone https://github.com/yourusername/smart-queue-management.git
cd backend
npm install
npm start
cd frontend
npm install
npm start
